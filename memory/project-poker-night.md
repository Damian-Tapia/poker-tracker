# Poker Night Tracker — MVP Status

Cash game home game tracker. Local-only, offline-first PWA. No backend, no auth, no accounts.

**Stack**: Next.js 16.3 (App Router, `output: "export"`), React 19.2, TypeScript strict, Tailwind v4 (`@theme inline` in globals.css, no config file), Vitest (node env).

**Rule**: zero runtime deps beyond React/Next. No Zustand, Dexie, next-pwa, icon libs, UI kits.

## Architecture

```
core/models/domain.ts           Player, Session, SessionPlayer, Transaction, RoundResult
core/logic/session-math.ts      summarizePlayer, summarizeSession, checkIntegrity, round2, chipsInPlay, moneyForChips
core/logic/settlement.ts        settle() — greedy debtor/creditor matching
core/store/poker-store.ts       localStorage-backed store, useSyncExternalStore tripleta
core/hooks/use-poker.ts         reactive hooks (usePlayers, useSession, useSessionPlayers, etc.)
hooks/use-mounted.ts            hydration gate (useSyncExternalStore pattern, not useEffect)
components/ui/                  Button, Chip, Dialog, ConfirmDialog, IntegrityDialog, Money, Avatar, SuitIcon, PlayerFormDialog
components/session/             SeatTable, SeatActionsDialog, AddSeatDialog, SettlementView
components/AppShell, BottomNav, RegisterServiceWorker
app/page.tsx                    home — active sessions + quick links
app/players/page.tsx            CRUD (create/edit/delete)
app/session/new/page.tsx        new session form
app/session/page.tsx            active session hot path + closed session settlement view
app/history/page.tsx            closed sessions list
app/stats/page.tsx              lifetime stats per player
app/backup/page.tsx             export JSON + merge/replace import
```

## Build status (2026-08-10)
- tsc --noEmit: clean
- vitest run: 19/19 passing

- PWA: manifest.json, sw.js (network-first nav, cache-first assets), icons generated by scripts/generate-icons.mjs (pure node:zlib, no deps)

## Key decisions / constraints
- Static export: no server — all routes must be prerenderable. useSearchParams wrapped in <Suspense>.
- Module-level store state: single-tab only. Two open tabs diverge silently (acceptable for home game).
- Greedy settlement, not NP-optimal (fine for <12 players).
- Copy in Spanish rioplatense.
- `public/icons/` is gitignored — regenerated on predev/prebuild.
- Capacitor config placeholder only — `npx cap add ios` on /out when needed.

## Open gaps
- No tests for store or UI.
- Stats page uses "USD" hardcoded for per-player display — should use per-session currency.
- Deleting a player orphans transactions (playerId stays, UI falls back to "Jugador borrado").
- Multiple open sessions allowed by store; UI navigates to latest (not stress-tested).
- RoundResult model exists but not wired to UI.

**Why**: MVP scope. All were explicit or implicit exclusions from the spec.
**How to apply**: don't add these features without asking; they're known gaps not bugs.
